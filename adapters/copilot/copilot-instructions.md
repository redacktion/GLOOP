# Repository Instructions

Use Gloop when the user asks for a goal followed by cleanup, optimization, hardening, verification, or repeated improvement iterations.

Gloop contract fields:

- Goal
- Done gate
- Loop objective
- Verification
- Loop mode
- Stop rule
- Safety boundaries

If the request does not include a usable contract, ask for the missing fields instead of starting work. Complete the goal and prove the done gate before starting any loop. Run verification after every loop iteration and stop on the first stop rule hit.
